# Paradise Nursery Shopping Application

Paradise Nursery is a responsive front-end web application designed for houseplant enthusiasts to browse, select, and manage plants for purchase. 

---

## Features

* **Landing Page:** Welcoming interface introducing Paradise Nursery with a direct call-to-action to begin shopping.
* **Product Catalog:** Browse a diverse selection of houseplants, categorized by type with names, pricing, and visual previews.
* **Cart Management:** 
  * Add plants directly to the shopping cart from the product listings.
  * Real-time cart badge displaying the total quantity of selected items.
* **Shopping Cart:**
  * Dedicated view listing all selected plants with unit prices and sub-totals.
  * Dynamically adjust item quantities (increment, decrement, or remove).
  * Automatically calculated total purchase cost.
  * Checkout button with an instant order summary prompt.

---

## Tech Stack

* **Front-End:** React.js / HTML5, CSS3, JavaScript (ES6+)
* **State Management:** React Context API or Redux (cart state and quantity tracking)
* **Styling:** CSS Modules / Modern Responsive CSS
